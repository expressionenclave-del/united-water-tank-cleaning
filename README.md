# United Water Tank Cleaning Service Website

React + Vite + TypeScript + Tailwind CSS.

- Run locally: `npm install` then `npm run dev`
- Build: `npm run build` (output folder: `dist`)
- Edit business details, services, steps and FAQs in `src/config.ts`
- Deploy: build command `npm run build`, output directory `dist`
